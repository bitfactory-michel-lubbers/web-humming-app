Instagram Cover Picker

A bookmarklet that runs inside your own, already-logged-in Instagram tab — no separate login, no server, nothing here ever sees your session. It scans your carousel posts and suggests which slide would make the strongest cover.

This page hosts nothing that touches Instagram. The bookmarklet below only starts running once you click it while you're already on instagram.com, logged in as yourself. Everything happens in your own browser tab from that point on.

1. Install the bookmarklet

Drag this link to your bookmarks bar:

📌 Pick Instagram Covers

(If dragging doesn't work, right-click your bookmarks bar → Add page → paste the link shown below as the URL.)

2. Use it

  1. Go to instagram.com and log in normally, as you always do.
  2. Open your own profile page.
  3. Click the Pick Instagram Covers bookmark.
  4. First time only: it'll ask for an Anthropic or OpenAI API key (stored only in your browser's localStorage — never sent anywhere except directly to that provider's API from your own browser).
  5. A panel appears in the corner of the page showing progress and, for each carousel post found, which slide it recommends as the cover.
What this version does not do yet: it only reports suggestions — it does not change any post. Actually changing a carousel's cover depends on whether Instagram's "Edit" screen even exposes that (see the main README) — that's still unconfirmed, so this cut stops at "here's what I'd recommend" rather than guessing at how to apply it.

Note: if you're viewing this page by double-clicking the local file, some browsers block the fetch below over file://. Serve this folder with npx serve (or open it via the real GitHub Pages URL once merged) if the bookmarklet link stays broken.
